# Włoski krok po kroku

**⚠️ Wersja demo.** Postępy zapisują się tylko w przeglądarce.

Aplikacja do nauki włoskiego i angielskiego dla osób mówiących po polsku.

**Funkcje:** lekcje według poziomów, fiszki ze słówkami, powtórki w odstępach czasowych (SRS), testy, gramatyka, statystyki postępów.

**Uruchomienie:** otwórz `index.html` w przeglądarce. Postępy zapisują się lokalnie w przeglądarce (localStorage), nic nie jest wysyłane na serwer.
