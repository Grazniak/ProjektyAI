# Moje Przepisy (wersja demo)

Aplikacja do prowadzenia własnej bazy przepisów kulinarnych, działająca jak aplikacja mobilna (PWA): kategorie, wyszukiwanie, przeliczanie porcji, tryb gotowania krok po kroku z odhaczaniem, zdjęcia, notatki, eksport i import kopii zapasowej.

**To jest wersja demonstracyjna.** Oryginał zapisuje przepisy w prywatnej bazie danych zabezpieczonej PIN-em. W tej publicznej wersji nie ma żadnej bazy ani kluczy dostępu: krótki skrypt na początku `index.html` udaje serwer, a przepisy przykładowe i wszystko, co dodasz, zapisuje się tylko w Twojej przeglądarce (localStorage). Żadne dane nie są nigdzie wysyłane.

**Uruchomienie:** otwórz `index.html` w przeglądarce (najlepiej przez https, np. GitHub Pages).
